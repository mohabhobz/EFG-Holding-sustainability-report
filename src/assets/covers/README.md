# Section cover artwork

Five images, one per numbered section. Drop a file in here named for the
section and it appears on that section's cover; until then the slot draws
itself as a labelled dashed box.

| file | section |
|---|---|
| `introduction.jpg` | Section One — Introduction |
| `environmental-stewardship.jpg` | Section Two — Environmental Stewardship |
| `social-investment.jpg` | Section Three — Social Investment |
| `governance-ethics.jpg` | Section Four — Governance & Ethics |
| `stakeholder-engagement.jpg` | Section Five — Stakeholder Engagement |

`.jpg`, `.png`, `.webp` and `.svg` all work — the stem is what matters.

**The slot is square-ish: 330 × 319 pt, the same box the report cover gives its
plaque.** An image of any shape is fitted to it and centre-cropped, so anything
close to square keeps all of itself. Supply it at 1,000px or wider.
